## 📖 Descripción General

El tema **Condenuedo** ofrece una solución limpia, modular y eficiente para tiendas en línea que buscan una experiencia de usuario (UI) moderna, rápida y responsiva. Integra profundamente las funcionalidades e interfaces estándar de WooCommerce dentro del flujo de utilidades CSS de Tailwind mediante la arquitectura que proporciona TailPress.

---

## 🛠️ Tecnologías Utilizadas

* **WordPress**: Motor CMS base.
* **WooCommerce**: Plataforma de comercio electrónico.
* **TailPress**: Starter theme base para integración de Tailwind CSS en WordPress.
* **Tailwind CSS**: Framework CSS orientado a utilidades.
* **PHP / JavaScript**: Lenguajes principales de backend/frontend.
* **Composer**: Gestor de dependencias PHP.
* **NPM**: Gestor de paquetes y automatización de assets.

---

## 📋 Requisitos Previos

Asegúrate de contar con los siguientes elementos instalados en tu entorno de desarrollo local o servidor:

* **WordPress** >= 6.0
* **WooCommerce** >= 7.0
* **PHP** >= 8.0
* **Node.js** >= 16.x
* **Composer** >= 2.x
